## 이 노트에 대하여 { #about-these-notes }

이 노트는 과목 가운데 기말고사 범위만 다룬다. 기말 범위는 두 부분으로 나뉜다.

- **1부 — 양자역학**: 3차원 양자역학 중 수소 원자에 한정한다. 구면좌표에서 슈뢰딩거 방정식의 변수분리, 르장드르 방정식과 버금 르장드르 방정식, 구면조화함수, 그리고 교환자와 사다리 연산자를 이용한 각운동량의 대수적 취급을 다룬다. 6장 학습지와, 학습지가 기대고 있는 앞 장의 배경 내용을 바탕으로 했다. 지름 방정식은 다루지 않는다.
- **2부 — 상대론**: 특수상대론만 다룬다. 맥스웰 방정식과 빛의 속력, 속도의 합성, 벨의 우주선 역설, 전기력과 자기력의 상대성을 다룬다. 지금까지의 수업 필기를 바탕으로 했으며 수업이 진행되면서 늘어날 것이다.

그림은 새로 그렸고, 각 부는 그 부에서 쓰는 기호로 시작한다. 1부 끝에는 지난 기말고사에서 무엇을 물었는지 짧게 정리했다.

## 노트의 구성 { #how-these-notes-are-organised }

1부는 학습지의 절 번호(§6.0–§6.4)를 그대로 쓰고, 번호 붙은 항목은 절 안에서 센다. 그래서 **정리 6.3.4**는 §6.3의 네 번째 번호 붙은 항목이다. 2부는 자체 절 번호를 쓴다.

    새로운 용어. 용어 자체는 **굵게** 쓴다.

!!! abstract "정리"
    상자로 둘러싼 핵심 결과. 기억해 둘 만한 것이다.

!!! example "예제"
    구체적인 계산.

!!! info "참고"
    왜 그 단계를 밟는지, 또는 결과가 무엇을 뜻하는지 설명한다.
